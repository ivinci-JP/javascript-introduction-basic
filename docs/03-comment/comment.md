# コメントとは

コメントとはコードを明快にするため説明であり、JavaScriptはコメントを解釈しません。
必要であれば沢山のメモをコメントとして記載しても構わないし、不要になったら消してしまっても大丈夫です。

## 行コメント

- 行コメントは`//`（２つのスラッシュ）で始まり、改行で終わります
- 行頭に書くこともできるし、コードの後ろに書くこともできます。

```js
// これはコメント
const one = 1; // これもコメント
               // そしてこれもコメント
```

## 複数行コメント

- 複数行のコメントを書きたい場合は`/*`と`*/`を使います
- `/*`と`*/`に挟まれた内容は全てコメント扱いとなります

```js
/* 一行のコメント */
const one = 1;

/* 二行の
 * コメント */
const two = 2;

/* 三行
   の
   コメント */
const three = 3;
```
