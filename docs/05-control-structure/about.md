# 制御構造とは

制御構造とは、プログラミングにおいて命令が実行される流れ（処理フロー）をコントロールする仕組みです。基本となる「順次」「分岐」「反復」の3つの構造を組み合わせることで、複雑なプログラムの動作を組み立てます。

## 逐次（順次実行）

最も基本的なフローです。
記述された順番に上から下へと処理が流れる構造です。

## 分岐（条件分岐）

条件によって「もし〇〇ならAの処理、そうでなければBの処理」というように、実行する処理を切り替える構造です。代表例は`if`文などです。

## 反復（繰り返し）

特定の条件を満たしている間、同じ処理を何度も繰り返す構造です。代表例は`for`文や`while`文などです。
