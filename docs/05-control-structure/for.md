# for文(ループ)

`for`文は最も基本的な反復処理（ループ）です。
同じ処理を一定の回数だけ繰り返すために使用します。
ここまでに紹介した構文の中で一番むずかしいので、
実際にコードを実行しながら、じっくり動きを確認しましょう

## 構文の説明
```js
for (/* 処理化 */; /* ループ条件判定 */; /* 更新 */) {
    /* 繰り返したい処理 */
}
```

下記のサンプルコードは

```js
for (let i = 0; i < 3; i++) {
    console.log('繰り返し');
}
console.log('終了');
```
1. `i`が`0`に初期化される
2. `i < 3`は`true`なのでループを継続
3. `'繰り返し'`と出力される
4. `i`に`1`が代入される
5. `i < 3`は`true`なのでループを継続
6. `'繰り返し'`と出力される
7. `i`に`2`が代入される
8. `i < 3`は`true`なのでループを継続
9. `'繰り返し'`と出力される
10. `i`に`3`が代入される
11. `i < 3`は`false`なのでループを終了
12. `'終了'`と出力される

というフローで実行されます。
