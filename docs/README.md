# JavaScriptハンズオン 基礎編

## このドキュメントについて

本ドキュメントは本格的なプログラミングを始める前の練習として
簡単な[JavaScript](https://developer.mozilla.org/ja/docs/Web/JavaScript)の実際に書いて動かしてみる為の手引きです。
限られた勉強会の時間内でJavaScriptのコーディングを学習することを考慮し、
比較的コンパクトな内容にとどめています。

JavaScriptについてもっと詳しく知りたい場合は[MDN](https://developer.mozilla.org/ja/docs/Web)
などを参照したり、Web検索などを活用して各自で補完して下さい。
JavaScriptに関するチュートリアルは通常、[HTML](https://developer.mozilla.org/ja/docs/Web/HTML)や[CSS](https://developer.mozilla.org/ja/docs/Web/CSS)などの技術とセットで扱われることが殆どですが、
本ドキュメントでは出来る限りHTMLやCSSに依存しない、純粋なJavaScriptに関して記述します。

## 対象読者

- プログラミング経験がない方
- プログラミングを始めるきっかけが欲しい方
- JavaScriptに興味がある方

内容が難しくなり過ぎない様に配慮していますが、初めてのプログラミングとはどうしても難しいものです。
また、プログラミングは本を読んだり、誰かに習っただけでは身に付きません。
自分自身で書きながら、考えたり調べたりする中で少しずつ身に付くものなのです。
やる気と根気をもって読み進めて下さい。
