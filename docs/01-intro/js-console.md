# JavaScriptコンソールを使ってみる

本格的なプログラミングを開始するには幾つかの準備が必要ですが、
幸いなことに、JavaScriptには「JavaScriptコンソール」があるので、簡単に試してみることができます。
まずはそれを起動しましてみましょう。

## JavaScriptコンソールを起動する

JavaScriptコンソールはChromeからすぐに起動することがでします。
Chromeのウィンドウ右上部のメニューボタン（`︙`）をクリックし、
`[その他のツール]->[デベロッパーツール]`と辿って下さい。
(キーボードの`F12`キーを押すことでもデベロッパーツールを起動できます)

![alt text](./img/js-console-01.png)

起動したデベロッパーツールの画面から`[Console]`をクリックし、
画面をJavaScriptコンソールに切り替えましょう。

![alt text](./img/js-console-02.png)
