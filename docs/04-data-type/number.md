# number(数値型)

数値型のことを正式にはnumber型と呼びます。
ここまで学んできた通り、number型では数値の計算をすることができます。
`+`, `-`, `*`, `/`などの演算子を使った四則演算の他にも色々な計算を行うことが出来ます。

## 剰余（割り算した余り）

剰余を求めるには`%`（パーセント記号）演算子を使います。

```js
console.log(10 % 3); // 1
console.log(12 % 5); // 2
```

## べき乗

べき乗を求めるには`**`演算子を使います。

```js
console.log(3 ** 2); // 3 * 3 = 9
console.log(3 ** 3); // 3 * 3 * 3 = 27
console.log(3 ** 4); // 3 * 3 * 3 * 3 = 81
```
